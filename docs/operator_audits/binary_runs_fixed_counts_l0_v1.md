## Scientific-code failure

The estimator's formulas are numerically correct, and its own sandbox plus the
independent reviewer exercised formula cases, malformed inputs, complement,
reversal, and determinism. The reviewer ran one broad Python probe with 30 estimator
invocations and explicitly claimed that all outputs were JSON values and all
invalid public inputs were rejected.

Two public closed-ABI requirements were nevertheless missed:

- The source checks `isinstance(value, int)` without excluding `bool`, so Python
  booleans satisfy the integer test even though the visible ABI requires exact JSON
  integers and explicitly rejects booleans.
- `scipy.stats.norm.cdf` is returned without conversion to a native Python float.
  The value is numerically correct but is not guaranteed to satisfy the ABI's
  JSON-native scalar boundary.

The hidden algorithm process executed successfully, but its acceptance checks
failed on valid, invalid, complement/reversal, and closed exact/finiteness groups;
only determinism and nonmutation passed. The same source still passed the separate
empirical dimension because that lane exercised large valid sequences and numeric
behavior rather than exact transport types.

This is a model-owned implementation and reviewer test-selection failure. It is not
evidence for hardcoding Python type cases into AgentRuntime, feeding hidden findings
back to the model, adding another reviewer, or building a repair state machine. One
consumed draw is insufficient to justify a shared mechanism change. A future
disjoint task can test whether reviewers independently translate explicit public
edge semantics into executable probes.
