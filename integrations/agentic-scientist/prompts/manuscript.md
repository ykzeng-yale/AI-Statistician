# Statistical And Biostatistical Methods Manuscript

Write from the selected research artifacts and actual evidence. The inherited
layout is a provisional upstream template, not journal-format certification.
Match the scientific question, estimand, assumptions, method, results and
interpretation. State whether this is reproduction, rederivation, an extension,
a candidate new method, a negative finding or unfinished work. Do not invent
novelty, human review, experimental results or theorem correctness.
Match the requested scientific scope. Do not fabricate a simulation, application
or AI-system comparison to fill a template when the brief does not require it.

Main text should establish the methodological motivation and closest work, define
the inferential problem, explain the method and its stated guarantees, summarize
informative simulations and the substantive application, and discuss limitations.
An application needs data provenance and a question it can answer, not a generic
regression table. EHR work must explain relevant timing, observation, confounding,
missingness, censoring and dependence assumptions rather than use an EHR template.

The supplement supplies complete assumptions and mathematical arguments, lemma
dependencies, conditions for invoked results, algorithms and exact experiment
designs. Use justified aligned derivations, not JSON theorem cards. Inspect the
theory/code correspondence; compilation or simulation cannot fill a proof gap.
Separate an incomplete proof from a demonstrated false assertion.

For simulation, report ADEMP, comparators, actual repetitions, failures, precision
and Monte Carlo uncertainty. Distinguish exploratory, confirmatory and post-hoc
measurements. Inner datasets, agent runs and reviewer calls are different units.
Report all scheduled conditions, including no-winner or non-qualifying outcomes;
manuscript completion is not research success.

Keep main text, supporting derivations, tables, figures and code synchronized.
Every numerical claim must trace to the actual selected evidence. A correct
symbolic result for a different expression is not evidence for the target claim.
Use the upstream `scientific-evidence` references, sidecars and verifier instead
of inventing another ledger. A resolved or anchored provenance link is not proof
of its mathematical content or an independent scientific acceptance.
Explain AI assessment, operator involvement and unassessed claims explicitly.
Optional Lean evidence names the exact source statement, project and axiom scope;
do not turn partial formalization into full-method verification.

Produce scientific plots from recorded data using local code. Do not request
Autoillustrate, generate-concept-figure, image enhancement or external manuscript
review in this local-Qwen condition. These are not needed to establish a methods
result. Final journal formatting and source rights remain separate release work.
