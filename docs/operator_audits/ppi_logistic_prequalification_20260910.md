## Shared Harness Correction

The completed run demonstrated a separate efficiency problem: later qualification
sessions continued after a required frozen control had already failed. The current
evaluator now stops after the first failed control assessment, preserves completed
review workspaces and reports an unreviewed candidate as NOT_RUN with zero claim
assessments. A skipped control is not counted as passed. Passing qualification still
requires every control and the complete reference review; a failed record cannot
authorize startup. Within-case review passes and model/tool budgets are unchanged.

Protocols 16/17 bind this changed execution contract. Model prompts, scientific
labels, tools, model choice and acceptance thresholds are unchanged. No new agent,
tool, module, exception family or configuration switch was introduced. Production
code is net +1 line. The old protocol-15 run was finished before editing code and
remains exactly as recorded; no savings or improved mathematical judgment are
claimed for it. Fresh qualification under the new contract remains unestablished.

Focused semantic/gold/core tests passed 112 in 12.35 seconds; the full suite passed
1359 in 287.32 seconds, with compileall and diff checks passing. The shared change
is committed at `3e4aa402`; [current status](../main_worker_status.json) records it.
These tests establish execution and
authority behavior, not scientific capability. Remaining scientific feedback
projections and truncation require separately justified, blinding-preserving work;
neither this change nor the earlier feedback deletions resolve the whole design.
