## Shared Harness Defect

The accepted algorithm handoff contained the exact reviewed estimator source,
its ABI, and the complete 4,000-replicate smoke result. The same full handoff
was copied into `runtime_environment_feedback`, including a nested Architect
context, and the Simulation prompt separately added a nominally compact handoff.
The raw accepted handoff was about 4.7 MB; the duplicated live feedback was
about 6.8 MB. Anthropic rejected the resulting 1,130,071-token request before a
model response.

This was a shared artifact-projection failure, not a control-variate defect and
not evidence that Haiku lacked context or scientific ability. Increasing the
model limit, trimming this task's equations, reducing replicate counts, or
adding a simulation fallback would have hidden the architecture error.

## Shared Correction

Code commit `dd3cb36c236e360c52f397998464997b0c08c7c8` applies the mechanism
already selected in the pinned OpenAI Codex harness audit:

- authoritative source and raw outcomes remain in content-addressed artifacts;
- accepted execution handoffs retain exact reviewed source and immutable hashes
  but refer to smoke outcomes by hash instead of copying them;
- model sampling receives one bounded dependency projection containing
  estimator identity, language, dependencies, source/result hashes, and the
  complete accepted ABI;
- every recursively carried `upstream_algorithm_handoff` is removed from the
  generic environment-feedback projection before that explicit dependency view
  is added once;
- the runtime executor still injects and runs the exact reviewed estimator
  source, so the model cannot silently substitute an implementation.

An offline replay using the immutable live handoff reduced 6.8 MB of raw
feedback to a 45,314-byte complete planning prompt. The estimator ABI and
source/result hashes remained visible; source bytes and all historical outcomes
were absent. Two pathological projection regressions, 43 focused tests, and the
full `815/815` suite passed. `research_agent_runtime.py` remains at its existing
24,999-line regression ceiling; no new scheduler, router, agent, retry, tool,
model call, statistical rule, Lean rule, or task-family branch was added.

This is future-task mechanism evidence only. The frozen run was not resumed and
the failed Simulation request was not retried.
