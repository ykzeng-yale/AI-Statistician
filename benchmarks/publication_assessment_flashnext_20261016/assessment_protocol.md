## Question And Reused Sources

arguments, a false extrapolation, honest incompleteness and an active false extra

This is a new model, runtime and review-interface condition, not a retry or

## Panel And Information Boundary

Five ordered controls use the original two complete proof routes, false
unrestricted-model argument, honest missing argument, and correct proof with a
false supplementary identity. The old duplicate positive candidate-mode check
is omitted: the native workspace has no separate candidate-review mode.
The five combinations are purposive diagnostics, not independent research draws
or a population accuracy estimate.

Each case starts an isolated retained session on the same fixed model. Logical
file grants expose only the question, obligations, exact candidate Markdown and
prepared reference Markdown. The reviewer writes its own findings and submits
PASS, FAIL or UNCERTAIN for each obligation. It receives no answer key, expected
labels, earlier reports or numerical outcomes. There is no scratch executor,
live search, extra reviewer, source patcher or mathematical decision rule.
No original PDF is silently treated as a model-readable input.

The private frozen condition records expected whole-candidate dispositions.
Any FAIL makes the overall disposition FAIL; otherwise any UNCERTAIN makes it
UNCERTAIN; otherwise it is PASS. Per-obligation judgments and all substantive
reasons are retained rather than forced to match a particular vector.
Execute all five frozen controls once, even after a label mismatch; this gives
the complete planned diagnostic panel, not a chance to replace the mismatch.
An execution error stops the panel and leaves later cases NOT_RUN. No retry,
post-terminal report repair, replacement judge or result-conditioned model
change is allowed. Inputs and consumed outputs stay immutable.

## Scientific Decision

Every expected disposition must match. That is necessary but insufficient.
One declared examination compares the exact retained Markdown reports with the
prewritten analytic key: the decisive arguments must be supported; both valid
routes must be recognized; missing proof must not be confused with an active
false assertion; and the false supplementary claim must not be excused by a
correct target proof. A reference cannot fill a missing candidate argument.
Unsupported numerical or source-verification claims are material defects.

The caller never marks scientific qualification established. Matched labels
leave argument examination pending. Missing reports, unsupported decisive
reasons, mismatches and incomplete cases remain unsuccessful observations.
Even a successful examination would qualify only this task-bound source-review
component, not arbitrary mathematics, the common multi-family external endpoint,
newly enabled public discovery, research-E2E or publication efficacy. Q05 and
the official study remain open until their actual broader requirements hold.
