## Design Judgment

The focused inspection covered the shared retained loop, Theory/scientific/Lean
workspaces and independent semantic judge. No production source, prompt, tool,
budget, statistical case handler or repair branch changed in this qualification.
The latest production correction remains deletion of the Lean opening/continuation
diagnostic whitelist at `9fd90d88`, not a recipe for interpreting compiler errors.

The referee already receives complete files and optional ordinary Python/R scratch.
Its prompt explicitly distinguishes absent support from contradiction, says scratch
is not proof, and requires no tool count or derivation length. Thus this observation
does not establish a missing instruction or transport defect. Do not add a print
ban, mandatory scratch ritual, report-to-label parser or GEE-specific instruction.
Moving such a recipe from Python into a prompt would still overfit the case.

Exact diagnostic-label qualification may be imposing too much operational weight
on two nonaccepting dispositions. That is an unresolved evaluation-design question,
not permission to relabel this result or bypass its frozen gate. Acceptance
reliability, diagnosis quality and scientific capability must remain separately
reported. Repeating full qualification on another topic is not a remedy for this
already-observed disagreement; no replacement task is activated by this audit.
