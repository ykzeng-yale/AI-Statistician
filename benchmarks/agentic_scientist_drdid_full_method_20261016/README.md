the population-argument assessor panel, any consumed HC0 arm, a held-out study or

inference, the original ordinary simulation grid (160,000 datasets), all original

condition. The modern pinned package environment differs from the historical
one; neither omission nor numerical agreement permits whole-paper replication.

bytes and an unimplemented seed, and attaches fixed requirements plus the native
posthoc plan. `evaluate.py` only launches the model-authored project and checks
complete record accounting. Its execution metric and upstream `correct` field
do not judge DGP fidelity, estimator validity, numerical reproduction, mathematical
truth or manuscript accuracy. Separate source-bound model review is fallible;
the common external publication authority remains unqualified. This development
may yield useful artifacts without any independently accepted research result.

statistical formula in this preparation. All adaptation and research source are
authored by the research model. The current `ProgramWorkspace` directly returns
official execution/review observations; the same model chooses any new source
version. Consumed versions remain immutable. Source-only internal review does not
see observed numerical results; artifact-only posthoc sees declared summaries,
not private author/reviewer conversations, and cannot execute new science.
