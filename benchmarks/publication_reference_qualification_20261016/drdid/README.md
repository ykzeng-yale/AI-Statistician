## Computational Scope

The two-page original README maps all estimator, simulation and application
entry points. The panel and repeated-cross-section main scripts each use four
DGPs, sample sizes 500/1000, 10,000 replications, seed 1234 and fourteen workers;
the cross-section entry uses sampling share 0.5. Thus their complete grids contain
160,000 datasets, not 160,000 independent agent runs. The main paper's n=1000
study and the archive's additional n=500 cells must remain distinguishable.
Separate efficiency-bound entries specify 1,000 replications of size 10,000,000
for each of four DGPs in both structures. Those original settings are not silently
replaced by a small smoke study or by the model's finite Monte Carlo checks.

The application entry uses the supplied NSW data, three samples and three
covariate specifications, with its original estimator and table helpers. The
package's short example is not the complete original application. Scientific
interpretation, estimator/inference agreement and all discrepancies still need
assessment; no application or simulation has run in this preparation.
