# Ledoit-Wolf linear covariance shrinkage: public method record

## Primary source

Olivier Ledoit and Michael Wolf, "A well-conditioned estimator for
large-dimensional covariance matrices," *Journal of Multivariate Analysis*
88(2):365-411, 2004. DOI: `10.1016/S0047-259X(03)00096-4`.

Author-hosted article:
<https://www.econ.uzh.ch/dam/jcr:ffffffff-935a-b0d6-ffff-ffffceb83f14/wellCond.pdf>

This record is an operator-authored mathematical index of the published method.
It is not a copy of the article and does not contain implementation source,
hidden benchmark cases, expected numerical results, or evaluator thresholds.

## Statistical object

The paper's exact finite-sample oracle analysis takes `x_1,...,x_n` to be
independent mean-zero `p`-vectors with covariance `Sigma` and finite fourth
moments, and uses

```math
S=\frac1n\sum_{k=1}^n x_kx_k^\top.
```

Thus `E[S]=Sigma` in that derivation. The executable task also supports unknown
location. When `assume_centered=false`, it instead forms

```math
z_k=x_k-\bar x,\qquad
S_z=\frac1n\sum_{k=1}^n z_kz_k^\top
```

and applies the same feasible shrinkage computation to `S_z`. This practical
centering convention must not be silently inserted into the paper's exact
finite-sample Pythagorean identity: under iid sampling with an unknown mean,
`E[S_z]=(n-1)Sigma/n`, so the unbiasedness argument is no longer literal. Mean
estimation may be asymptotically negligible in an appropriate regime, but that is
different from an exact finite-sample equality. In the formulas below, `S` denotes
the paper's mean-zero covariance unless the implementation-centered matrix `S_z`
is named explicitly.

The task deliberately uses the maximum-likelihood normalization `1/n`, not the
unbiased `1/(n-1)` normalization. Define the normalized Frobenius inner product
and norm by

```math
\langle A,B\rangle_p=\frac1p\operatorname{tr}(AB^\top),
\qquad \lVert A\rVert_p^2=\langle A,A\rangle_p,
```

and set

```math
\mu=\langle\Sigma,I_p\rangle_p,\qquad
a^2=\lVert\Sigma-\mu I_p\rVert_p^2,
```

```math
b^2=\mathbb E\lVert S-\Sigma\rVert_p^2,\qquad
d^2=\mathbb E\lVert S-\mu I_p\rVert_p^2.
```

The orthogonality of `S-Sigma` and `Sigma-mu I_p` in expectation gives
`d^2=a^2+b^2`. Under quadratic Frobenius risk, the oracle member of the affine
class generated by `I_p` and `S` is

```math
\Sigma^*=\frac{b^2}{d^2}\mu I_p+\frac{a^2}{d^2}S,
```

when `d^2>0`. The paper then replaces the unobservable scalars with sample
counterparts. In paper notation,

```math
m=\langle S,I_p\rangle_p,\qquad
\hat d^2=\lVert S-mI_p\rVert_p^2,
```

```math
\widetilde b^2=\frac1{n^2}\sum_{k=1}^n
\lVert z_kz_k^\top-S\rVert_p^2,
\qquad
\hat b^2=\min(\widetilde b^2,\hat d^2),
\qquad
\hat a^2=\hat d^2-\hat b^2.
```

For positive `hat d^2`, the feasible estimator is therefore

```math
\widehat\Sigma_{LW}
=\hat\lambda\,mI_p+(1-\hat\lambda)S,
\qquad
\hat\lambda=\frac{\hat b^2}{\hat d^2}\in[0,1].
```

When `hat d^2=0`, this task uses `hat lambda=0`; the sample covariance already
equals its spherical target, so the returned covariance is unchanged.

## Equivalent matrix computation

For the `n` by `p` matrix `Z` actually supplied to the covariance computation
(`Z=X` under known zero mean and `Z=X-1\bar x^\top` after sample centering), let
`Z2` denote elementwise squares and write `S_Z=Z^\top Z/n`.
The following scalar identities are useful for a vectorized implementation:

```math
B_0=\sum_{i,j}(Z2^\top Z2)_{ij},\qquad
D_0=\frac1{n^2}\sum_{i,j}(Z^\top Z)_{ij}^2,
```

```math
m=\frac1p\operatorname{tr}(S_Z),\qquad
\widetilde b^2
=\frac1{pn}\left(\frac{B_0}{n}-D_0\right),
```

```math
\hat d^2
=\frac1p\left(D_0-2m\operatorname{tr}(S_Z)+pm^2\right).
```

These identities are mathematical input to the task, not hidden source code.
An implementation must still establish dimensions, centering, numerical behavior,
the closed request/response contract, and the declared invariances itself.

## Claims and limits to audit

For `S` positive semidefinite, `m>=0`, and `hat lambda` in `[0,1]`, the convex
combination is positive semidefinite. If `m>0` and `hat lambda>0`, every eigenvalue
is at least `hat lambda*m`, so the estimate is positive definite even when `p>n`.
This statement does not imply strict positive definiteness when the shrinkage
intensity is zero or all observations have zero scale.

Sample centering makes the unknown-mean implementation translation invariant,
but it does not preserve the exact finite-sample unbiasedness premise used in the
paper's oracle projection. Simultaneous
positive rescaling of every entry scales the covariance by the square of the
factor while leaving the dimensionless shrinkage intensity unchanged. Feature
permutations conjugate the covariance by the same permutation and preserve the
intensity. These properties are weaker than arbitrary affine equivariance.

The article's risk optimality is an asymptotic statement for its stated
large-dimensional regime and moment assumptions. It is not a pointwise guarantee
that shrinkage beats the sample covariance for every finite dataset or every
population covariance. Finite simulation can test selected designs, not prove the
general risk theorem.

## Hidden implementation authority

After the product run, evaluator-only code may compare the submitted estimator
with an independently pinned implementation. That implementation, its cases,
seeds, expected values, and tolerances are deliberately absent from this public
snapshot.
