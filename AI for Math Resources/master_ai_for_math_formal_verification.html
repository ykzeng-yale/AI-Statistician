How the layers compose / 这些层怎么拼起来

Build a Lean RAG agent

Layer 1 mathlib/Lean kernel -> Layer 3 dependency graph + semantic search -> Layer 4 prover uses retrieved lemmas.

Build a conjecturer

Layer 5 creates examples/counterexamples/patterns -> Layer 2 formalizes claims -> Layer 4 proves/refutes them.

Build long-term skill memory

Layer 4 proves reusable lemma blocks -> Layer 3 indexes their utility -> Layer 5 reuses them in new discoveries.

Build multimodal verified reasoning

Layer 6 extracts visual/spatial structure -> Layer 2 turns it into formal specs -> Layer 1 verifies final logical claims.

Fastest reading route

0 -> 1 -> LeanDojo/ReProver -> DeepSeek/AlphaProof -> PatternBoost/Int2Int -> MMFormalizer/MathNet.

Implementation route

Start with Layer 3 (index mathlib), then Layer 4 (proof-state loop), then Layer 5 (generate new conjectures/data).

Research route

Focus on unsolved bridge: utility-aware lemma search, equivalence-aware transport, and visual structure grounding into Lean specs.
