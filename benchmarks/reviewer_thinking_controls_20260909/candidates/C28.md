# Candidate Derivation

For positive integers $n$ and $x\in[0,1]$, set
\[
g_n(x)=nx(1-x)^n.
\]
We determine whether $g_n$ converges to zero pointwise and uniformly.
For $0<x<1$, exponential decay dominates the factor $n$, so $g_n(x)\to0$.
Both endpoints have value zero. Thus the pointwise limit is zero everywhere.

For interior $x$,
\[
g'_n(x)=n(1-x)^{n-1}\{1-(n+1)x\}.
\]
The maximum is at $x_n=1/(n+1)$, with value
\[
\sup_{x\in[0,1]}g_n(x)
=\left(\frac{n}{n+1}\right)^{n+1}\longrightarrow e^{-1}.
\]
Consequently the convergence to zero is not uniform. The moving maximizer
does not contradict convergence at each fixed $x$.
